# LessBrower

基于安卓原生 WebView 的轻量浏览器，提供干净浏览体验。

## 功能特性

- 轻量级设计，启动速度快
- 基于原生 WebView，兼容性好
- 简洁干净的 UI 界面

## 技术栈

- Kotlin
- Android SDK
- WebView

## 编译运行

1. 使用 Android Studio 打开项目
2. 连接 Android 设备或启动模拟器
3. 点击 Run 按钮

## 项目结构

```
app/
├── src/main/
│   ├── java/com/less/browser/
│   │   └── MainActivity.kt
│   └── res/
└── build.gradle
```
